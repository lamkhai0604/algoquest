# Parked content

Lessons and problems written for an earlier level order and kept for a later level of the Learning Path. Nothing here is loaded by the app or validated in CI.

- `two-pointers/`: the former level 3, intended for the Two Pointers level (Problem-Solving Patterns).
- `L2-exact-total.json`: a running-sum problem, intended for the Prefix Sum level.

Before reuse, files are moved into the level folder and their `id` and `level` fields are renamed to the new level number.
