# Basics

## Learning objectives

- Find the largest value in one pass.

## Problem hook

Find the largest number.

## Intuition

Keep the best so far.

## When to use

You need one answer from every item.

## Template code

```js
let best = -Infinity;
```

## Complexity

O(n) time, O(1) space.

## Common mistakes

Forgetting the empty array.

## Edge cases

An empty array has no largest value.

## Worked example

Max of [3, 9, 4] is 9.
