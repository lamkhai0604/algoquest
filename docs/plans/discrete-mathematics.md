# Discrete Mathematics track: plan

Status: planned (D-089). Content starts after the System Design track is complete. This plan does not change any level, unlock rule or content file.

## Purpose

A suggested first track for learners who want the mathematics behind algorithm analysis and graph algorithms. Learners are not required to start here (D-089).

## Placement and numbering

- Map position: first, before the algorithm track, with a suggested start.
- Levels are numbered after the System Design track (after Level 53), so no existing level number changes.
- Each level follows the standard lesson template (CONTENT-GUIDE.md section 2) and its own content files.

## Draft level outline

Each line is a candidate level. Order and count are open until content work starts.

| Order | Topic                                           | Prepares the learner for                    |
| ----- | ----------------------------------------------- | ------------------------------------------- |
| 1     | Sets, logic, and truth tables                   | Conditions and proofs                       |
| 2     | Proof techniques (direct, contradiction, cases) | Correctness arguments                       |
| 3     | Induction and recursion                         | Recursive algorithms and divide and conquer |
| 4     | Counting: products, permutations, combinations  | Search space sizes                          |
| 5     | Probability basics and expected value           | Randomized algorithms and average cost      |
| 6     | Relations, functions, and modular arithmetic    | Hashing and number-theoretic algorithms     |
| 7     | Graphs: vertices, edges, paths, connectivity    | Graph algorithms                            |
| 8     | Trees and spanning structures                   | Minimum spanning tree (see T-695)           |
| 9     | Recurrence relations and their solutions        | Analysis of recursive algorithms            |
